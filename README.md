## 📌 About the Project

**Vishal Rajput and Hospitality – Medical Billing Software** is a front-end web application designed to create clean, professional medical bills and printable customer receipts.

The application provides a modern blue-and-white interface with organized patient details, medicine entry, automatic bill calculations, discount handling, and print-ready receipts.

The project is developed using **HTML5, CSS3, and Vanilla JavaScript**, without any front-end framework.

## ✨ Features

- 🎨 **Modern UI:** Clean, professional blue-and-white dashboard.
- 🧑‍⚕️ **Patient Details:** Enter customer name, mobile number, doctor name, bill number, and date.
- 💊 **Medicine Management:** Add multiple medicines and remove unwanted items.
- 🧮 **Automatic Calculation:** Calculate subtotal, discounts, tax amount, and grand total.
- 🧾 **Printable Receipt:** Print bills or save them as PDF through the browser.
- 🏥 **Hospital Branding:** Display hospital name, address, and contact number on every receipt.
- 💳 **Payment Options:** Select Cash, UPI, Card, or Credit.
- ✍️ **Additional Notes:** Add optional instructions to the receipt.
- 🖱️ **Interactive UI:** Hover effects, input focus states, and interactive buttons.
- 📱 **Responsive Design:** Adapted for desktop, tablet, and mobile screens.
- ⚡ **Lightweight:** Built with plain HTML, CSS, and JavaScript.
- 🔧 **Easy to Customize:** Simple project structure for beginners and developers.

## 🚀 Getting Started

Follow these steps to run the project on your local computer.

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Open the Project Folder

```bash
cd vishal-hospital-billing
```

### 3. Open in Visual Studio Code

```bash
code .
```

### 4. Run the Application

**Option A — Live Server**
1. Open the project in VS Code.
2. Install the Live Server extension if it is not already installed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

**Option B — Browser**
- Open `index.html` directly in your preferred browser.

No npm installation or build process is required.

## 🧾 How to Use

1. Open the billing application.
2. Enter the patient or customer details.
3. Add medicine names, quantities, rates, and discounts.
4. Review the automatically calculated bill.
5. Enter the tax amount manually if applicable.
6. Select **Print Receipt**.
7. Choose a printer or select **Save as PDF**.

## 🌐 Deploy with GitHub Pages

You can host this static front-end project using GitHub Pages.

1. Push the project files to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Click **Save**.
6. Wait for deployment and open the published URL shown in the Pages settings.

Your application will then be accessible through its GitHub Pages URL.

## ⚠️ Current Limitations

- This version is a front-end demo and does not include a backend or database.
- Bills are not permanently saved; refreshing the page may lose unsaved details.
- Medicine inventory and stock tracking are not implemented.
- Tax/GST is entered manually; the application does not determine applicable tax rules.
- The interface is not a substitute for verifying legal, pharmacy, healthcare, and invoice requirements before real-world use.

**Important:** Do not enter real patient information into a publicly hosted demo. Add appropriate security, access controls, and data protection before handling sensitive information.
